Performance Index (PI) analysis

KVS-style grade-weighted Performance Index. Subject PI is calculated separately for each subject; overall PI uses the first five subjects listed for each candidate.
Formula: Subject PI = Σ(N × W) ÷ (appeared × 8) × 100. Overall PI = Σ(N × W) across the five main subjects ÷ (total candidates × 40) × 100. Grade weights: A1=8, A2=7, B1=6, B2=5, C1=4, C2=3, D1=2, D2=1, E=0. If a grade is absent in the gazette, it is estimated from marks using standard grade bands.
